Initial public release of the redesigned Afterburner Helper integration.

## Highlights

- Canonical fuel, remaining-runtime, and price-at-time-of-use cost accounting
- Temperature-based automatic start and stop control
- Flameout detection and bounded low-fire recovery
- Manual-stop latch and persistent control state
- Optional phone-presence Home/Away climate package
- Dashboard examples, 23 unit tests, and GitHub Actions validation
