# Security policy

Please do not publish credentials, precise home locations, internal hostnames,
or unredacted Home Assistant diagnostics in an issue.

For a vulnerability that could expose Home Assistant data or permit unintended
control, use GitHub's private vulnerability reporting for this repository when
available. For ordinary bugs, open a public issue with sensitive values removed.

This integration coordinates an existing Afterburner controller; it does not
replace the heater's stock ECU or its shutdown sequence. Test control changes on
your own installation and retain an independent way to stop the heater.
