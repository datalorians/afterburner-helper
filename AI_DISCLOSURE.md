# AI development disclosure

This project has been developed with substantial assistance from generative AI,
primarily OpenAI Codex and ChatGPT.

AI assistance has been used for code generation and refactoring, test creation,
documentation, data analysis, and implementation planning. A human operator
defined the requirements, supplied real heater telemetry, chose the control
behaviour, reviewed the results, and supervised testing on physical hardware.

AI-generated work can contain mistakes. Inclusion in this repository is not a
claim that a change was independently verified, formally certified, or suitable
for every heater installation. Contributions should be reviewed and tested in
the same way as any other open-source code.

When contributing AI-assisted changes, please:

1. disclose material AI involvement in the pull request;
2. describe the testing performed;
3. avoid submitting generated code that you do not understand; and
4. verify that generated material does not introduce confidential information
   or incompatible licensing.
